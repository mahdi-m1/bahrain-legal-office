# مهارة كتابة التقارير والمذكرات

## الهيكل الإلزامي
1. العنوان + رقم المرجع + التاريخ
2. الأطراف
3. ملخص الوقائع (من الاستخراج فقط)
4. المسائل القانونية
5. التحليل مع الاقتباسات الحرفية من المصادر الرسمية
6. التوصيات / أسباب الطعن
7. تذييل: مستوى الثقة + تنبيه المراجعة البشرية

لغة عربية فصحى قانونية بحرينية.
