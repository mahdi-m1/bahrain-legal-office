# مهارة استخراج البيانات من المستندات الحساسة (يقيني)

## القواعد الصارمة
1. لا تعتمد على OCR وحده أبداً.
2. إذا ثقة الاستخراج < 85% → ضع علامة NEEDS_HUMAN_REVIEW ولا تكمل التحليل النهائي.
3. استخرج فقط ما هو موجود فعلياً. ممنوع الافتراض.
4. كل حقل مع: القيمة + الموضع إن أمكن + مستوى الثقة.

## الحقول الإلزامية
- رقم القضية / رقم الحكم
- تاريخ الحكم / تاريخ المستند
- المحكمة (الدرجة + الدائرة)
- الأطراف
- منطوق الحكم أو الطلبات
- المواد القانونية المذكورة صراحة
- التواريخ المهمة

## صيغة الإخراج
احفظ JSON في extracted/ وملخصاً نصياً. إذا needs_human_review=true احفظ أيضاً في review/.
